# MoviePilot-NewbieVillage

「影音新手村」—— MoviePilot v3 插件，面向影视/音乐新手的通关手册：

- **术语词典**：影视命名 / 音乐命名 / PT 行为 / MP 概念四领域词条，一句话解释 + 详细说明 + 真实命名示例
- **命名解析器**：纯正则离线解析文件名，逐段高亮（M2 交付）
- **联动预告**：解析后按你的真实目录配置预告"这个文件会被整理到哪"（M2 交付）
- **实战案例**：真实踩坑故事线（音乐入库失败、H&R、硬链接跨盘、NFS stale……）
- **每日一词**：仪表盘卡片，按日轮换

## 安装

MoviePilot v3 → 设定 → 插件市场 → 添加自定义市场源：

```
https://github.com/huhubeibei/MoviePilot-NewbieVillage/
```

## 说明

- 仅支持 MoviePilot **v3**（vue 联邦前端）
- 词典支持远端刷新（不升级插件即可更新词条），见插件配置页
