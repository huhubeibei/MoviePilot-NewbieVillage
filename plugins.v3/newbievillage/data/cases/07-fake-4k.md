# 下了个 4K 怎么不像 4K？假 4K 鉴别三步法

## 现象

文件名标着 2160p，放出来却糊得像 1080p；或者 4K 资源的体积只有 4~8GB，和动辄 40GB 的正规 4K 完全不是一个量级。

## 排查

1. **看体积**：真 4K WEB-DL 普遍 10~25GB、REMUX 40GB+。一部 2 小时的电影标 2160p 却只有 4GB，先打个问号。
2. **用 MediaInfo 看码率**：真 4K 的视频码率通常 30Mbps 起步；AI 超分/锐化的假 4K 码率明显偏低（常常不到 15Mbps）。
3. **查官方源**：上 TMDB/ blu-ray.com 查这部片有没有发行过官方 UHD 蓝光或 4K 流媒体版本——官方都没有 4K，文件名却标 2160p，必假。

## 结论

- 假 4K 的本质：从 1080p/720p 用 AI 超分或锐化"做"出来的 2160p，像素多了、真实细节没变，锐化过头还会出白边。
- 三个鉴别信号：**体积异常小、码率异常低、官方没有 4K 版**。三者占其二基本可以判定。
- 对策：优先从有考核的 PT 站拿 UHD 资源；公开网站标注 2160p 的资源用上面三步过一遍。

## 关联设置

- **MediaInfo**：免费工具，拖入文件即看真实编码/码率，验片必备
- **洗版**：收到假 4K 后按标准命名重新订阅洗版
- **过滤规则组**：把低体积的组合条件过滤掉，从源头避开
